## Bug Pattern

The result of a `duplicator` call is passed to a `length_of` call before its possible NULL return is checked. If the duplication fails and returns NULL, the `length_of` operation dereferences NULL.

Roles:
- `duplicator` / `null_on_failure`: `xmlStrdup`
- `length_of`: `strlen`
- `allocator`: `xmlMalloc`
- `deallocator`: `xmlFree`

The missing check between the `duplicator` result and the `length_of` use is the root cause; the length must be calculated only after confirming that the duplicated buffer is non-NULL.
