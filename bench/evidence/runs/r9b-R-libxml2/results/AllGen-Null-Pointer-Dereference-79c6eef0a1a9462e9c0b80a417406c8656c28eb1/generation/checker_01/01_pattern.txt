## Bug Pattern

The result of a `duplicator` / `null_on_failure` call is passed to a `length_of` operation before its NULL return value is checked. If allocation inside the duplication fails, the `length_of` call dereferences a NULL pointer.

### Roles

- `duplicator` / `null_on_failure`: `xmlStrdup`
- `length_of`: `strlen`
- `allocator`: `xmlMalloc`
- `deallocator`: `xmlFree`
