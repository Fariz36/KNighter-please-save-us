## Bug Pattern

Passing a potentially NULL `const char *` argument to a `%s` format directive in a diagnostic/error message without first validating that the pointer is non-NULL. If a caller passes NULL, the `%s` conversion has undefined behavior and may crash or produce incorrect output. The fix adds an argument assertion (`GIT_ASSERT_ARG(value)`) before `value` can be used in `git_error_set(..., "%s", value)`.
