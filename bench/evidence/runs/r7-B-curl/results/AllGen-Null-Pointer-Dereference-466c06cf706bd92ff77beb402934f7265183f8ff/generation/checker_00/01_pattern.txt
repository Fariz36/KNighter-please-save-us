## Bug Pattern

The bug pattern is dereferencing a caller-provided pointer parameter without first checking it for NULL. In `curl_url_dup(const CURLU *in)`, the function allocates the output object and then immediately uses `in` through `DUP(u, in, ...)` and direct field accesses like `in->portnum`, causing a NULL pointer dereference if the caller passes `NULL`. The fix adds an early guard:

```c
if(!in)
  return NULL;
```

before any use of `in`. This pattern applies to public API functions that accept handles or pointers and assume they are non-NULL.
