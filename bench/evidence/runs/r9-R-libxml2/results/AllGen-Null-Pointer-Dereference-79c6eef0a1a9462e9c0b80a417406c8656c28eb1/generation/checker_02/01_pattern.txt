## Bug Pattern

The result of a `duplicator` / `null_on_failure` call is passed to a `length_of` operation before that same result is checked for `NULL`. If duplication/allocation fails, the length computation dereferences a null pointer.

Roles:
- `duplicator` / `null_on_failure`: `xmlStrdup`
- `length_of`: `strlen`
- `deallocator`: `xmlFree`
- `allocator`: `xmlMalloc`
