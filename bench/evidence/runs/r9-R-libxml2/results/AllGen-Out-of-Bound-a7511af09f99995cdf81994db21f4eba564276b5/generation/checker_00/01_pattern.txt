## Bug Pattern

The bug pattern is an unchecked indexed read from a parser input buffer. An accessor macro dereferences `buffer[current + index]` without verifying that the resulting offset is within the buffer’s valid length. When the parser cursor is near the end of the input, a lookahead index can read past the allocated string, causing an out-of-bounds read.

Roles:
- `indexed_read`: `NXT` (expands to `ctxt->cur[index]`)
- `length_of`: `strlen` (used to compute `ctxt->len`, which the fixed macro compares against)
