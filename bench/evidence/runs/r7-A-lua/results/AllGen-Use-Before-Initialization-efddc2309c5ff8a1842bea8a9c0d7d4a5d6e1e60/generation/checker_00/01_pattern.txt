## Bug Pattern

The bug pattern is failing to reset mutable match state before every match attempt when that state is reused across calls to an iterator and can be left modified by an error path.

Specifically, `MatchState.matchdepth` was initialized only in `prepstate()`, while `gmatch` keeps the `MatchState` in a long-lived iterator closure. During matching, `matchdepth` is decremented recursively and normally restored on successful return. If `luaL_error()` is triggered, a non-local jump exits the match without restoring `matchdepth`. A later call to the same `gmatch` iterator then reuses the stale `matchdepth` value, potentially negative, so the recursion/stack-overflow guard no longer works correctly and the iterator can be left in an inconsistent state.

The fix is to reset `matchdepth` in `reprepstate()` before each match attempt, alongside `level`, so transient per-match state is always reinitialized even after previous errors.
