## Bug Pattern

The bug pattern is **failing to reset mutable per-invocation state in a reusable iterator before each use, especially after an error**. In `string.gmatch`, the long-lived `MatchState` keeps `matchdepth` as a recursion/C-stack guard. It was initialized only once in `prepstate()`, while `reprepstate()`—called before each match attempt—only reset `level` and assumed `matchdepth` was still `MAXCCALLS`. If a match raises an error (e.g. “pattern too complex”), `matchdepth` is left decremented, possibly negative. Later calls to the same gmatch iterator then start with stale, corrupted `matchdepth`, so the recursion/overflow check no longer behaves correctly. The fix moves `matchdepth = MAXCCALLS` into `reprepstate()` so every match attempt reuses clean per-call state.
